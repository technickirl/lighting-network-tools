Groups
A group is Luminex's name for a VLAN: a name, a VLAN ID and the ports in it. Reading changes nothing. Naming groups sends only the new names; ports and VLAN IDs are sent back as they are and checked afterwards.
Fixtures
RDM fixtures on every LumiNode, from the ports with RDM on. Reading asks each fixture over Art-Net and changes nothing. To turn RDM on for a port, open the node with Configure and use its RDM tab.
sACN view
Shows the levels arriving on each sACN universe and who is sending them. It only listens: nothing here changes a level or a device. Universes that a console announces are added by themselves; type any others.
sACN control
A small sACN source for testing a rig without a console: patch fixtures, set levels, then Start output. Nothing is sent until then, and it never starts by itself. While it is sending, any node listening to these universes puts the levels on its outputs.
